## 已核对的行为

### 游戏控制与观测

核对本机生成接口中的输入、原生交易、技能、地图、出航、世界对象及战役标识。状态来自当前加载岛屿的注册表，不按旧版左右 60 单位、各 16 项裁切。游戏对象读取与动作执行在 Unity 主线程，HTTP 线程只接收命令和快照。

测试覆盖 P2 身份与 P1 隔离、控制编号撤销、迟到指令拒绝、心跳失联、F8、交易完成/中止、移动目的地无进展、菜单及跨岛恢复。原生调用回执不等于真实建设、战斗或通关已成功。

0.5.1 用可控时钟和调用计数验证：加载/过场不枚举全场，200 个付款对象不会随每次 P2 更新重复扫描；动态敌人约 250 ms、战略信息约 1 秒、场景发现约 2 秒。钱包和当前付款对象仍快速读取。暂停地图可操作，恢复游玩、场景切换会刷新或清除缓存。反射只缓存类型、成员、方法等元数据，实际原生值每次重新读取；后加载程序集使未找到的类型缓存失效。

HTTP 测试验证 `Publish` 不执行世界序列化，24 个并发读取共享同一份 JSON，下一份快照按需更新。上述证据验证工作量和线程路径，没有对真实游戏进行帧时间或启动耗时采样。

0.5.2 检查本机生成的 `Sided<T>` 字段、索引和当前加载器转换函数，定位 float 字段双重装箱；替身保留错误字段值、提供正确索引值，验证三个边界各自正确与无效范围返回未知。Python 验证家园来自城堡和原生边界、目标分类不受 P1 位置影响、全部目标保留、外侧候选按边界距离计算、矛盾范围不伪造。

请求检查验证固定目录按标识排序、动态位置和目标更新不改变目录前缀、重复 nearby 去重、原始桥接状态不被修改，示例包字符数低于旧表示的 70%。缓存用量取自服务商 `usage`；缺失返回保持未知，统计只覆盖当前后台进程。没有发送真实模型请求，字符数降低不能直接当作 token 或账单节省比例。

0.5.3 将目录独立为实时消息前的一条完整消息，并将稳定战略信息排在时间戳和人物位置之前。200 对象的测试验证表格编码可按列还原每一行，包含完整标识、原始坐标、false/0 等值；没有按数量或范围删掉当前对象。去重仅删除与本轮观测完全一致的当前历史副本，价格不同、未出现或较旧的事实仍保留。本次样例的目录与动态事实字符数低于未精简表示的 65%，这不是缓存命中率或实际 token 降幅。

Ollama 模拟服务验证 `/api/chat` 原生请求、按操作生成的 schema、关闭思考、上下文大小、等待时间与保留加载设置；兼容服务密钥不发给本地执行服务。慢执行期间聊天仍调用主服务，停止能取消待返回动作，活跃游玩期间配置切换被拒绝。404、400、500、截断及非法动作没有隐式云端回退；缺少本地缓存字段时保持未知。旧配置迁移和主配置编辑保留独立执行配置与受保护密钥，读取模型列表不下载、加载、监听或操作游戏。用量按地址、模型及通道区分。本机发现 Ollama 已安装，但检查时 11434 服务未连接，尚未验证真实小模型推理。

### 共享记忆、阶段计划和聊天

- 战役标识隔离存档，跨岛保留已观测对象、资源、任务、目标和行动摘要；无可靠标识时不写入持久战役历史。
- 历史对象附观测时间，未出现不等于摧毁；P2 到达位置的最小/最大范围不证明整个区间都已探索。
- 经济、防御、进攻、出航等阶段有目标、可观测完成条件、失败提示和替代方案；未知条件保持待观测，计划不作为新增权限门槛。
- “今晚守右边”须在安排后实际观测夜晚，再见白天才能完成；留钱修船的偏好不把经济主任务误切成出航。
- 普通聊天不停止游玩，目标更新使尚未派发的旧决策失效；急停和常见安排绕过慢聊天，保留原来的玩法和货币支配方式。
- 模拟模型测试验证共享上下文、条件式安排、讨论/引用与动作格式；尚未发送真实服务请求验证语义质量。

### 语音与界面

- 设备枚举不打开麦克风；选择单独保存名称和后端，设备编号变化可恢复，已选设备消失时不静默切换输入。
- 人工 PCM 与假流验证 RMS/峰值、停止归零、短暂溢出后重置半句并继续监听、严重错误与积压诊断。
- 完整语音按顺序排队；满队列、事件遗漏和处理失败显式提示，不再仅保留最后一句。
- Vosk 中文模型可加载，静音 PCM 可输入真实识别引擎；这不验证真实麦克风或中文识别准确率。
- 临时后台界面检查输入设备、默认输入缺失诊断、音量表及阶段面板，浏览器没有控制台警告或错误。测试页面和进程已关闭。
- 启动检查确认四个静态文件与源码逐字节一致，设备与执行配置 API 需要页面会话，用量统计与营地上下文可读取。在临时配置中保存/读取/切回执行来源不启动 AI；麦克风和播报保持关闭，授权退出后进程正常结束。没有游戏命令、真实模型请求、收音或播报。

### 安装与卸载

安装测试在系统临时目录创建无效占位游戏和假存档，自行编译假 Unity 版本资源；不执行加载器或游戏。验证令牌生成与复用、版本检查、文件与存档按字节备份、清单复制、DryRun 只读及卸载还原。

卸载保留外部修改、新日志、其他模组、存档和备份。测试仅替换存档发现目录，其余文件、令牌和清单逻辑使用正式脚本；测试不读取真实存档。

加载器内 Il2CppInterop 的版本已核对为 `1.5.1-ci.845+f03c8f4ae507d47ea814f3d11d1ec6b0391c1576`，依赖准备固定此提交及对应源码、GPL/LGPL 文本，不用其他稳定版本冒充其对应源码。

## 复现

在项目根目录运行，按 [README](../README.md) 准备 Python 与 .NET SDK 8。前端测试另需 Node.js。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check companion tests
node --test tests/ui-state.test.cjs tests/ui-payment.test.cjs tests/ui-independent.test.cjs tests/ui-companion-features.test.cjs tests/ui-chat.test.cjs

$dotnetPath = (Get-Command dotnet -ErrorAction Stop).Source
& $dotnetPath run --project mod/tests/KingdomAI.DomainTests -c Release
& $dotnetPath run --project mod/tests/KingdomAI.EngineTests -c Release
.\.venv\Scripts\python.exe scripts/test-bridge-integration.py --dotnet $dotnetPath
```

项目 `.tools/dotnet/dotnet.exe` 也可替换 `$dotnetPath`。跨进程脚本使用随机回环端口，配置和日志写入独立系统临时目录，退出时释放模拟输入。不要将真实游戏桥接配置传给测试 Host。

安装卸载回归需要项目 `.tools/dotnet/dotnet.exe` 来编译假版本资源：

```powershell
.\scripts\test-installation.ps1
```

桥接与 EXE 的构建命令见 [README](../README.md)。构建产物、缓存、本机报告、私密配置和游戏接口均不提交到 GitHub。

## 实机待验收

1. 模组加载、原生输入与 F8 接管；P1/P2 互不干扰及长时间运行性能。
2. 各战役的移动、疾跑、付款、丢币、特殊技能、单位、地图、出航和跨岛效果。
3. 所选设备能正常打开，收音音量、长句/噪声下的识别、实际延迟与监听播报同时使用。
4. 真实模型理解安排、闲聊与讨论，阶段完成/失败判断及重复行为后的策略调整。
5. 跨岛和重启后的存档隔离、记忆恢复、连续 P2 自由游玩与战役通关。
6. 所选 Ollama 模型的 JSON/语义质量、首次加载与持续决策延迟、游戏同时运行时的显存占用；新版 Ollama 对超出上下文请求的明确报错，以及真实服务商缓存命中变化。

离线通过不证明上述实机结果，也不证明 AI 已具备可靠的完整通关战略。实机检查由玩家进入自己的本地合作存档完成。
